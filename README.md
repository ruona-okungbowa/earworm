# Earworm

Earworm hides the difficult browser-audio work such as framing, detection, calibration, timing, playback gating and replay, behind a small set of reusable TypeScript packages. Applications can then focus on their own rules and experience instead of rebuilding audio infrastructure.

The project is designed as a Skeleton Crew: one reusable interaction kit supporting multiple applications with different goals.
